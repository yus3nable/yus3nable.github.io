# 阅读室设计

界面以个人阅读资料为主体，使用系统衬线标题与系统无衬线正文。暖白、炭黑和陶土色由用户明确指定，与现有图文站点保持同一色系。色彩 token 集中在 `src/style.css`。

采用 design-taste-frontend 的 typography-first 方向，方向为 Type and nothing else，seed 144069612；结合 minimalist-ui 的平面、暖色与文字层级。入口使用三份真实资料及其主题设计的原创 SVG 封面，不使用人物、装饰性库存照片或虚构的第四份资料。封面是导航插画，不冒充原书封面。

主操作是选择资料或搜索正文。目录由同一份 JSON 生成，页面数量由各站实际公开索引计算。继续阅读只展示浏览器中实际打开过的链接。

Claude 暖色系是用户的明确品牌要求，对 taste-skill 的通用配色禁用规则采用注明理由的例外。源代码 lint 结果为 0 FAIL、0 WARN。

视觉验收尚未完成：按用户要求委派的 Terra 子代理缺少 Computer Use 浏览器控制与截图工具，没有更换模型或以其他浏览器自动化代替。桌面、平板和手机断点已写入 CSS，但没有宣称经过真实浏览器验证。
