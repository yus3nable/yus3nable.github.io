# 我的阅读室

yus3nable 的个人图文阅读入口，采用暖白、炭黑和陶土色。首页收录公开的课程与书籍站点，支持类型筛选、跨站正文搜索和本机最近打开记录。

网站：https://yus3nable.github.io/

## 内容来源

`data/library.json` 是资料目录的唯一来源。每项记录标题、简介、类型、主题、阅读地址和原站搜索索引地址。类型使用“课程”“书籍”“文章”；单个视频的图文稿、访谈和独立分享归入“文章”。现有课程和书籍保留原始阅读地址，首页提供统一入口；正文搜索结果直接链接到原站对应页面。

`src/` 保存首页模板、样式和交互代码，`scripts/build.py` 生成 `docs/`。GitHub Pages 从 `main` 分支的 `/docs` 发布，`.nojekyll` 关闭 Jekyll 处理。运行时不依赖外部字体、JavaScript CDN、数据库或账号服务。

## 更新与构建

在项目根目录运行：

```sh
python3 scripts/build.py --sync-search
python3 -m http.server 8787 --bind 127.0.0.1 --directory docs
```

打开 http://127.0.0.1:8787/ 。首次构建会下载目录中各站的公开搜索索引；`--sync-search` 强制刷新。省略参数时复用本地索引缓存。Python 仅使用标准库，索引下载使用本机 `curl`。

新增资料时，在 `data/library.json` 添加记录，再运行构建、检查，并提交源文件与 `docs/`。正文应先完成润色、配图和来源核对，再接入目录。源视频、原始 PDF、转写草稿和其他私人资料不进入该仓库。

搜索索引在首次输入关键词时加载，按标题和正文匹配。若索引请求失败，页面会显示错误和重新加载入口，资料目录仍可阅读。搜索索引属于各站的发布快照，正文更新后须重新同步构建。

顶部 A−、A+ 可在 14–22px 之间调整网页基础字号，点击中间的数值恢复 16px。字号设置和最近打开的链接只保存在当前浏览器，跨设备不自动同步。JavaScript 关闭时，三份资料的静态阅读入口仍可使用。

## 检查记录

`maintenance/source-sites.json` 记录收录站点，`maintenance/build.json` 记录索引覆盖范围，`maintenance/checks.json` 记录实际结构和内容检查。浏览器视觉与交互验收的执行状态单独记录，不以语法或结构检查代替。
