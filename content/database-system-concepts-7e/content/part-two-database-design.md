# 第二部分 数据库设计 {#part-two-database-design}

<!-- SOURCE pdf-0268-b006 -->
创建数据库应用是一项复杂工作，包括设计数据库模式、编写访问和更新数据的程序，以及设计控制数据访问的安全机制。用户需求贯穿设计过程。本部分重点介绍模式设计，同时简要说明其他设计任务。

<!-- SOURCE pdf-0268-b007 -->
第6章的实体—联系（E-R）模型是一种高层数据模型。它区分称为实体的基本对象，以及对象间的联系，无需先将全部数据表示成表，通常用作数据库模式设计的第一步。

<!-- SOURCE pdf-0268-b008 -->
前面已非形式化地介绍关系模式设计。判断设计好坏还可依据一些原则，这些原则通过不同范式加以形式化。各范式在发生不一致的可能性与某些查询效率之间作出不同取舍。第7章介绍关系模式的形式化设计。
