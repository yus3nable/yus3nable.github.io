# 第三部分 应用设计与开发 {#part-three-application-design-and-development}

<!-- SOURCE pdf-0392-b007 -->
关系模型的一项基本要求是数据值具有原子性，核心关系模型不允许多值、复合及其他复杂类型。但在许多应用中，这种类型限制带来的麻烦超过了好处。第8章介绍多种复杂类型，包括应用开发中广泛使用的半结构化数据、基于对象的数据、文本数据和空间数据。

<!-- SOURCE pdf-0392-b008 -->
数据库几乎总是通过应用程序使用，用户也主要通过应用间接与数据库交互。以数据库为后端的应用遍布 Web 和移动平台。第9章介绍构建应用的工具与技术，重点是用数据库存取数据的交互应用。
