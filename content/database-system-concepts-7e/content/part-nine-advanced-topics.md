# 第九部分 高级专题 {#part-nine-advanced-topics}

<!-- SOURCE pdf-1202-b006 -->
第24章进一步展开第14章的索引结构，详细介绍此前简述的 LSM 树及其变体、位图索引、空间索引，以及动态散列技术。

<!-- SOURCE pdf-1202-b007 -->
第25章讨论应用开发中的多项任务。性能调优通过寻找并消除瓶颈、增加适当内存或磁盘等硬件来加速应用。基准测试用标准任务集衡量数据库性能。应用测试则需要生成数据库状态和测试输入，再检查查询或程序的实际输出是否符合预期。标准同样影响应用开发，本章概述多种相关标准。

<!-- SOURCE pdf-1202-b008 -->
第26章从数据库角度介绍区块链，说明它与本书其他部分介绍的传统数据库有何区别，以及这些特性如何实现。除比特币式算法与实现外，本章还重点讨论更适合企业数据库环境的其他方案。
