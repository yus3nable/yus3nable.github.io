# 第六部分 查询处理与优化 {#part-six-query-processing-and-optimization}

<!-- SOURCE pdf-0716-b007 -->
用户查询最终要在存储设备中的数据库内容上执行。通常将查询分解为较小操作，大致对应关系代数运算。第15章先介绍各操作的实现算法，再说明如何协调执行这些操作来完成查询；既包括处理远大于内存的数据的算法，也包括针对内存数据优化的算法。

<!-- SOURCE pdf-0716-b008 -->
同一查询有多种执行方法，成本可能相差很大。查询优化就是寻找成本最低的执行方法。第16章介绍成本估算、候选计划生成及最低成本计划选择，还介绍物化视图等加速查询的技术。
