# 第四部分 大数据分析 {#part-four-big-data-analytics}

<!-- SOURCE pdf-0494-b006 -->
传统关系数据库应用面向单个企业的结构化数据。现代应用则常需处理非关系形式的数据，规模也远超传统单一组织所产生的数据量。第10章从大数据系统使用者和程序员的角度，介绍管理这类“大数据”的技术。先讨论存储，再介绍 MapReduce、代数操作、流数据与图数据库等查询处理技术。

<!-- SOURCE pdf-0494-b007 -->
大数据的一项主要用途是数据分析，即从数据中推断模式、相关性或预测模型。正确决策可能带来可观收益，错误决策也可能造成巨大损失，因此组织会投入资源收集或购买数据，并建设分析系统。第11章介绍数据分析，重点是利用历史预测未来、再据此决策的任务，内容包括数据仓库、联机分析处理和数据挖掘。
