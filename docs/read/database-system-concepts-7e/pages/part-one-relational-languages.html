      第一部分 关系语言

      数据模型是一组描述数据、数据之间的关系、数据语义及一致性约束的概念工具。关系模型用一组表表示数据及其联系。由于概念简单，它得到广泛采用，本书写作时绝大多数数据库产品都基于这一模型。它在逻辑层和视图层描述数据，屏蔽底层存储细节。

      要让用户使用关系数据库中的数据，就需要解决如何表达检索与更新请求的问题。本部分介绍为此开发的多种查询语言。

      第2章介绍关系数据库的基本概念，以及关系代数这一形式化查询语言。关系代数构成 SQL 的基础，而 SQL 是最广泛使用的关系查询语言，本部分将详细介绍。

      第3章概述 SQL，包括数据定义、查询基本结构、集合操作、聚合函数、嵌套子查询及数据库修改。

      第4章进一步介绍连接表达式、视图、事务、数据库强制执行的完整性约束，以及控制用户访问和更新权限的授权机制。

      第5章介绍高级 SQL，包括从程序设计语言访问 SQL、函数、过程、触发器、递归查询和高级聚合。
